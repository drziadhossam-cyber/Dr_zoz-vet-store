# Dr_Zoz Vet Store

منصة إلكترونية (واجهة أمامية فقط، بدون أي تكلفة استضافة) باسم Dr_Zoz Vet Store لعرض المنتجات البيطرية في مصر، مع إمكانية الاستفسار عن التوفر عبر WhatsApp.

**ملاحظة مهمة:** لا يعرض هذا الموقع أي أسعار في أي مكان، لا في بطاقات المنتجات ولا في صفحة التفاصيل ولا في رسائل واتساب. الهدف من الموقع هو العرض والتعريف بالمنتجات وتسهيل الاستفسار عن توفرها فقط.

هذا المشروع **Static بالكامل**: صفحات HTML + CSS + JavaScript، وبيانات المنتجات في ملف JSON واحد. لا يحتاج أي سيرفر أو قاعدة بيانات أو API مدفوع.

**كل ملفات المشروع في مجلد واحد مسطّح (بدون أي مجلدات فرعية)** — هذا مقصود ومهم: بعض خدمات الاستضافة (خصوصًا الرفع المباشر للملفات "Upload assets") تفشل أحيانًا في رفع المجلدات الفرعية بشكل صحيح إذا لم يتم اختيار طريقة الرفع الصحيحة، فتُفقد ملفات CSS وJS والصور ويظهر الموقع بدون أي تنسيق. تسطيح الهيكل بالكامل يمنع هذه المشكلة نهائيًا مهما كانت طريقة الرفع.

## 2. عدد المنتجات وتصنيفها

يحتوي `products.json` حاليًا على **127 منتجًا بيطريًا حقيقيًا ومعروفًا** (وليس بيانات وهمية)، موزّعة كالتالي:

**الأدوية البيطرية (58 منتج):**
مضادات حيوية، أدوية طفيليات وديدان، فيتامينات ومكملات، مطهرات، أدوية أخرى.

**الأدوات والمستلزمات (69 منتج):**
مستلزمات العيادات، سرنجات وإبر، قفازات، شاش وقطن، مستلزمات طبية عامة، مستلزمات مزارع، مستلزمات حيوانات أليفة، مستلزمات دواجن، مستلزمات أبقار وأغنام وماعز، مستلزمات خيول.

كل منتج يحتوي: الاسم، الشركة المصنعة (أو "غير متوفر حاليًا" إن لم تكن معروفة بثقة)، الفئة، الحيوان المستهدف، وصف مختصر، الاستخدام العام، وصورة توضيحية خاصة به. **لا يوجد أي حقل سعر في قاعدة البيانات إطلاقًا.**

### بخصوص الصور — مهم
لم يتم استخدام صور فوتوغرافية حقيقية لعبوات المنتجات، لأن معظم صور العبوات والمنتجات البيطرية التجارية (Baytril، Ivomec، Frontline، BD، إلخ) هي ملكية فكرية وتصوير منتج مملوك لشركاتها المصنّعة أو للمتاجر التي تبيعها، ولا يمكن تأكيد ترخيص استخدامها بشكل موثوق عبر هذه الأداة. ولتفادي عرض صورة منتج مختلف بدل المنتج الصحيح، تم توليد **صورة توضيحية مستقلة لكل منتج على حدة**: كل صورة SVG خفيفة الحجم جدًا (~1-1.3 كيلوبايت) تحمل اسم المنتج نفسه مكتوبًا عليها + أيقونة تناسب تصنيفه، وتوضّح بشكل صريح أنها "صورة توضيحية — لا تمثل عبوة حقيقية". الصور كلها في مجلد المشروع الرئيسي مباشرة (مثل `med-001.svg`، `too-042.svg`...).

يمكنك استبدال أي صورة بسهولة بصورة حقيقية موثوقة الحقوق لاحقًا (راجع الخطوة 3 أدناه).

## 3. ماذا أفعل بعد نسخ الملفات؟ (خطوة بخطوة لمبتدئ تمامًا)

### الخطوة 1: جرّب الموقع على جهازك أولًا

المتصفح أحيانًا يمنع تحميل ملف `products.json` عند فتح `index.html` مباشرة (بالنقر المزدوج). لذلك شغّل خادمًا محليًا بسيطًا:

**إذا كان عندك Python مثبت (يأتي مع ويندوز 10/11 ومعظم أجهزة Mac):**
1. افتح مجلد المشروع في الطرفية (Terminal / Command Prompt).
2. نفّذ الأمر:
   ```
   python -m http.server 8000
   ```
3. افتح المتصفح على: `http://localhost:8000`

**أو باستخدام إضافة VS Code:**
- ثبّت إضافة "Live Server" في Visual Studio Code، ثم اضغط بزر الفأرة الأيمن على `index.html` واختر "Open with Live Server".

### الخطوة 2: عدّل بيانات الموقع الأساسية

افتح ملف `products.json` وعدّل قسم `"settings"` في أعلى الملف:

```json
"settings": {
  "whatsappNumber": "201025739833",
  "contactEmail": "info@example.com",
  ...
}
```

- ضع رقم واتساب فعلي بصيغة دولية بدون علامة + وبدون مسافات (رقم الموقع الحالي 01025739833 مُخزَّن كـ `201025739833`).
- عدّل البريد الإلكتروني والعنوان ومواعيد العمل.

### الخطوة 3: عدّل أو أضف منتجات

كل منتج داخل `"products"` في نفس الملف عبارة عن كائن JSON بهذا الشكل:

```json
{
  "id": "med-001",
  "category": "medicines",
  "subcategory": "مضادات حيوية",
  "name": "اسم المنتج",
  "company": "الشركة المصنعة أو غير متوفر حاليًا",
  "animal": ["أبقار", "أغنام"],
  "description": "وصف مختصر للمنتج",
  "usage": "الاستخدام العام للمنتج",
  "image": "med-001.svg",
  "featured": false
}
```

- **لا تضف أي حقل سعر** — الموقع مصمم بالكامل بدون أسعار، وإضافة حقل سعر لن يظهر في الواجهة أصلًا لأن الكود لا يعرضه.
- لا تكتب اسم شركة أو معلومة لست متأكدًا منها — استخدم "غير متوفر حاليًا" بدلاً من التخمين.
- لتغيير صورة منتج: ضع صورتك (خفيفة الحجم، بصيغة jpg/png/webp أو svg) **مباشرة في نفس مجلد المشروع الرئيسي** (وليس في مجلد فرعي) وغيّر مسار `"image"` مثلاً `"image": "product-01.jpg"` — بدون أي `/` في الاسم. تأكد أن لديك حق استخدام الصورة قبل نشرها.

### الخطوة 4: انشر الموقع مجانًا

#### الخيار الأول: Cloudflare Pages (موصى به لهذا المشروع)
1. سجّل الدخول على [dash.cloudflare.com](https://dash.cloudflare.com).
2. من القائمة الجانبية: **Compute (Workers) ← Workers & Pages**.
3. اضغط **Create**، ثم اختر تبويب **Pages** (وليس Workers).
4. اختر **Upload assets / Direct Upload**.
5. اسحب **كل ملفات المشروع دفعة واحدة** (حدّد الكل بـ Ctrl+A أو Cmd+A داخل مجلد المشروع واسحبها معًا) إلى منطقة الرفع. بما أن كل الملفات في نفس المستوى بدون مجلدات فرعية، هذه الخطوة تعمل بشكل مضمون مهما كانت طريقة السحب.
6. اضغط **Deploy site**، وستحصل خلال ثوانٍ على رابط بصيغة `xxxx.pages.dev`.

#### الخيار الثاني: GitHub Pages
1. أنشئ حسابًا مجانيًا على [github.com](https://github.com) إن لم يكن لديك.
2. أنشئ Repository جديد (مثلاً باسم `dr-zoz-vet-store`).
3. ارفع كل ملفات المشروع (نفس الأسماء بالضبط، في نفس المستوى بدون مجلدات).
4. من إعدادات الـ Repository اذهب إلى: `Settings` > `Pages`.
5. اختر Branch: `main` والمجلد `/root`، ثم احفظ.
6. بعد دقيقة أو دقيقتين سيظهر رابط الموقع بصيغة: `https://username.github.io/dr-zoz-vet-store/`

#### الخيار الثالث: static.app (الأسرع لتجربة سريعة)
اذهب إلى [static.app](https://static.app) واسحب ملف الـ **ZIP** الخاص بالمشروع كما هو (بدون فك الضغط) — يصبح الموقع مباشرًا فورًا، بدون تسجيل حساب.

بعد النشر على Pages أو GitHub Pages، افتح ملفي `robots.txt` و`sitemap.xml` وغيّر `example.com` إلى رابط موقعك الحقيقي.

## 4. كيف يعمل الاستفسار عبر WhatsApp؟

- الموقع لا يستخدم أي WhatsApp Business API مدفوع، بل رابط "Click-to-Chat" العادي (`wa.me`) وهو مجاني تمامًا.
- عند الضغط على "اطلب عبر WhatsApp" في أي بطاقة منتج أو صفحة تفاصيل، يفتح واتساب برسالة جاهزة بالصيغة التالية بالضبط:
  > مرحبًا، أريد الاستفسار عن توفر منتج: [اسم المنتج]
- **لا يوجد أي سعر في أي رسالة واتساب**.
- من صفحة قائمة الاستفسار (`cart.html`) يمكن تجميع أكثر من منتج وإرسال استفسار واحد يحتوي أسماء المنتجات والكميات فقط.

## 7. استكشاف الأخطاء: الموقع يظهر بدون تنسيق (HTML خام)

إذا ظهر الموقع بدون ألوان أو تخطيط (روابط زرقاء تحتها خط، بدون بطاقات أو أزرار منسّقة)، فهذا يعني أن ملف `style.css` لم يتم رفعه أو لم يتم العثور عليه على الاستضافة.

**كيف تتأكد من السبب:** افتح الموقع، اضغط F12 لفتح Developer Tools، اذهب لتبويب Network، أعد تحميل الصفحة (Ctrl+R)، وابحث عن `style.css` — لو ظهر برمز 404 أو باللون الأحمر، فهذا يؤكد أن الملف لم يُرفع.

**لماذا كان يحدث هذا قبل تسطيح المشروع:** كانت الملفات موزّعة على مجلدات فرعية (`css/`, `js/`, `data/`, `images/`)، وبعض طرق الرفع المباشر (Upload assets) على استضافات مختلفة لا تحافظ دائمًا على المجلدات الفرعية إذا لم تُسحب بالطريقة الصحيحة بالضبط — أحيانًا يتم رفع الملفات الموجودة في المستوى الأول فقط (مثل `index.html`) بينما تُفقد المجلدات الفرعية بصمت.

**الحل المطبّق الآن:** تم تسطيح المشروع بالكامل — لا توجد أي مجلدات فرعية إطلاقًا، فكل الملفات (HTML وCSS وJS والصور وJSON) في نفس المستوى. هذا يزيل المشكلة نهائيًا بغض النظر عن طريقة الرفع، لأنه لا يوجد أي مجلد يمكن أن "يُنسى" أثناء الرفع.

**عند الرفع، تأكد من:**
- تحديد **كل الملفات** (وليس فقط `index.html`) قبل السحب أو الرفع.
- استخدام "Select All" (Ctrl+A / Cmd+A) داخل مجلد المشروع قبل السحب لمنطقة الرفع.
- التأكد بعد الرفع من ظهور جميع الملفات (وليس فقط صفحات HTML) في قائمة الملفات على لوحة تحكم الاستضافة، إن كانت تعرضها.

## 8. الانتقال لاحقًا لقاعدة بيانات حقيقية

المشروع الآن يعتمد على ملف `products.json` فقط. إذا رغبت لاحقًا في لوحة تحكم حقيقية لإدارة المنتجات، أو تحديث بيانات تلقائي، أو تسجيل دخول للعملاء أو الإدارة، يمكن حينها استبدال طريقة تحميل البيانات في `app.js` (دالة `vmeLoadData`) لتقرأ من خدمة مجانية مثل **Supabase** أو **Firebase** بدلاً من ملف JSON، دون الحاجة لإعادة بناء بقية الموقع، لأن كل الصفحات تتعامل مع البيانات عبر `window.VME.products` فقط.

## 9. ملاحظات مهمة قبل النشر الفعلي

- المنتجات المدرجة حاليًا هي أسماء وشركات بيطرية حقيقية ومعروفة عالميًا (مثل Baytril وIvomec وFrontline وغيرها)، لكن **يجب مراجعة توفرها الفعلي في مصر ومدى الترخيص والتسجيل الرسمي لها** مع الصيدلية/الجهة البيطرية المرخصة المتعاون معها قبل الإطلاق الفعلي.
- لا تكتب أن أي منتج "معتمد" أو أن الموقع "مرخص" إلا إذا كان لديك مستند رسمي يثبت ذلك.
- الموقع لا يعرض أي أسعار بتصميمه — إذا احتجت إضافة الأسعار مستقبلًا، فهذا يتطلب تعديل الكود (`products.js` و`cart.js` و`whatsapp.js`) بشكل مقصود.
- راجع صفحات "الشروط والأحكام" و"سياسة الخصوصية" و"إخلاء المسؤولية" وحدّث أي بيانات تواصل فيها.
- هذا المشروع لا يقدّم استشارة قانونية أو بيطرية؛ يُنصح بمراجعة جهة قانونية أو الهيئة المصرية للدواء البيطري بخصوص متطلبات عرض المنتجات الدوائية أونلاين قبل الإطلاق الفعلي.
