# Dr_Zoz Vet Store

منصة إلكترونية (واجهة أمامية فقط، بدون أي تكلفة استضافة) باسم Dr_Zoz Vet Store لعرض المنتجات البيطرية في مصر، مع إمكانية الاستفسار عن التوفر عبر WhatsApp.

**ملاحظة مهمة:** لا يعرض هذا الموقع أي أسعار في أي مكان، لا في بطاقات المنتجات ولا في صفحة التفاصيل ولا في رسائل واتساب. الهدف من الموقع هو العرض والتعريف بالمنتجات وتسهيل الاستفسار عن توفرها فقط.

هذا المشروع **Static بالكامل**: صفحات HTML + CSS + JavaScript، وبيانات المنتجات في ملف JSON واحد. لا يحتاج أي سيرفر أو قاعدة بيانات أو API مدفوع.

## 2. عدد المنتجات وتصنيفها

يحتوي `data/products.json` حاليًا على **127 منتجًا بيطريًا حقيقيًا ومعروفًا** (وليس بيانات وهمية)، موزّعة كالتالي:

**الأدوية البيطرية (58 منتج):**
مضادات حيوية، أدوية طفيليات وديدان، فيتامينات ومكملات، مطهرات، أدوية أخرى.

**الأدوات والمستلزمات (69 منتج):**
مستلزمات العيادات، سرنجات وإبر، قفازات، شاش وقطن، مستلزمات طبية عامة، مستلزمات مزارع، مستلزمات حيوانات أليفة، مستلزمات دواجن، مستلزمات أبقار وأغنام وماعز، مستلزمات خيول.

كل منتج يحتوي: الاسم، الشركة المصنعة (أو "غير متوفر حاليًا" إن لم تكن معروفة بثقة)، الفئة، الحيوان المستهدف، وصف مختصر، الاستخدام العام، وصورة توضيحية خاصة به. **لا يوجد أي حقل سعر في قاعدة البيانات إطلاقًا.**

### بخصوص الصور — مهم
لم يتم استخدام صور فوتوغرافية حقيقية لعبوات المنتجات، لأن معظم صور العبوات والمنتجات البيطرية التجارية (Baytril، Ivomec، Frontline، BD، إلخ) هي ملكية فكرية وتصوير منتج مملوك لشركاتها المصنّعة أو للمتاجر التي تبيعها، ولا يمكن تأكيد ترخيص استخدامها بشكل موثوق عبر هذه الأداة. ولتفادي عرض صورة منتج مختلف بدل المنتج الصحيح (وهو ما طُلب تجنبه صراحة)، تم توليد **صورة توضيحية مستقلة لكل منتج على حدة** (وليست صورة تصنيف عامة مشتركة بين عدة منتجات كما كان سابقًا): كل صورة SVG خفيفة الحجم جدًا (~2-4 كيلوبايت) تحمل اسم المنتج نفسه مكتوبًا عليها + أيقونة تناسب تصنيفه، وتوضّح بشكل صريح أنها "صورة توضيحية — لا تمثل عبوة حقيقية". الصور موجودة في `images/products/<id>.svg`.

يمكنك استبدال أي صورة بسهولة بصورة حقيقية موثوقة الحقوق لاحقًا (صورة من الشركة المصنّعة نفسها، أو صورة التقطتها أنت للمنتج الفعلي الذي تبيعه) — راجع الخطوة 3 أدناه.

## 3. ماذا أفعل بعد نسخ الملفات؟ (خطوة بخطوة لمبتدئ تمامًا)

### الخطوة 1: جرّب الموقع على جهازك أولًا

المتصفح أحيانًا يمنع تحميل ملف `data/products.json` عند فتح `index.html` مباشرة (بالنقر المزدوج). لذلك شغّل خادمًا محليًا بسيطًا:

**إذا كان عندك Python مثبت (يأتي مع ويندوز 10/11 ومعظم أجهزة Mac):**
1. افتح مجلد المشروع في الطرفية (Terminal / Command Prompt).
2. نفّذ الأمر:
   ```
   python -m http.server 8000
   ```
3. افتح المتصفح على: `http://localhost:8000`

**أو باستخدام إضافة VS Code:**
- ثبّت إضافة "Live Server" في Visual Studio Code، ثم اضغط بزر الفأرة الأيمن على `index.html` واختر "Open with Live Server".

### الخطوة 2: عدّل بيانات الموقع الأساسية

افتح ملف `data/products.json` وعدّل قسم `"settings"` في أعلى الملف:

```json
"settings": {
  "whatsappNumber": "201025739833",
  "contactEmail": "info@example.com",
  ...
}
```

- ضع رقم واتساب فعلي بصيغة دولية بدون علامة + وبدون مسافات (رقم الموقع الحالي 01025739833 مُخزَّن كـ `201025739833`).
- عدّل البريد الإلكتروني والعنوان ومواعيد العمل.

### الخطوة 3: عدّل أو أضف منتجات

كل منتج داخل `"products"` في نفس الملف عبارة عن كائن JSON بهذا الشكل:

```json
{
  "id": "med-001",
  "category": "medicines",
  "subcategory": "مضادات حيوية",
  "name": "اسم المنتج",
  "company": "الشركة المصنعة أو غير متوفر حاليًا",
  "animal": ["أبقار", "أغنام"],
  "description": "وصف مختصر للمنتج",
  "usage": "الاستخدام العام للمنتج",
  "image": "images/cat-medicine.svg",
  "featured": false
}
```

- **لا تضف أي حقل سعر** — الموقع مصمم بالكامل بدون أسعار، وإضافة حقل سعر لن يظهر في الواجهة أصلًا لأن الكود لا يعرضه.
- لا تكتب اسم شركة أو معلومة لست متأكدًا منها — استخدم "غير متوفر حاليًا" بدلاً من التخمين.
- لتغيير صورة منتج: ضع صورتك (خفيفة الحجم، بصيغة jpg/png/webp أو svg) داخل مجلد `images/` وغيّر مسار `"image"` مثلاً `"images/product-01.jpg"`. تأكد أن لديك حق استخدام الصورة قبل نشرها.

### الخطوة 4: انشر الموقع مجانًا

#### الخيار الأول: GitHub Pages
1. أنشئ حسابًا مجانيًا على [github.com](https://github.com) إن لم يكن لديك.
2. أنشئ Repository جديد (مثلاً باسم `vet-market-egypt`).
3. ارفع كل ملفات المشروع (نفس الهيكل بالضبط) إلى الـ Repository.
4. من إعدادات الـ Repository اذهب إلى: `Settings` > `Pages`.
5. اختر Branch: `main` والمجلد `/root`، ثم احفظ.
6. بعد دقيقة أو دقيقتين سيظهر رابط الموقع بصيغة:
   `https://username.github.io/vet-market-egypt/`

#### الخيار الثاني: Cloudflare Pages
1. أنشئ حسابًا مجانيًا على [pages.cloudflare.com](https://pages.cloudflare.com).
2. اختر "Upload assets" وارفع مجلد المشروع مباشرة (أو اربطه بحساب GitHub).
3. اضغط Deploy، وستحصل على رابط مجاني للموقع خلال ثوانٍ.

بعد النشر، افتح ملفي `robots.txt` و `sitemap.xml` وغيّر `example.com` إلى رابط موقعك الحقيقي.

## 4. كيف يعمل الاستفسار عبر WhatsApp؟

- الموقع لا يستخدم أي WhatsApp Business API مدفوع، بل رابط "Click-to-Chat" العادي (`wa.me`) وهو مجاني تمامًا.
- عند الضغط على "اطلب عبر WhatsApp" في أي بطاقة منتج أو صفحة تفاصيل، يفتح واتساب برسالة جاهزة بالصيغة التالية بالضبط:
  > مرحبًا، أريد الاستفسار عن توفر منتج: [اسم المنتج]
- **لا يوجد أي سعر في أي رسالة واتساب** — لا في رسالة المنتج الواحد ولا في رسالة قائمة الاستفسار المجمّعة من صفحة "السلة".
- من صفحة قائمة الاستفسار (`cart.html`) يمكن تجميع أكثر من منتج وإرسال استفسار واحد يحتوي أسماء المنتجات والكميات فقط.

## 6. الانتقال لاحقًا لقاعدة بيانات حقيقية

المشروع الآن يعتمد على ملف `data/products.json` فقط. إذا رغبت لاحقًا في:
- لوحة تحكم حقيقية لإدارة المنتجات دون تعديل الكود يدويًا.
- تحديث بيانات المنتجات تلقائيًا.
- تسجيل دخول للعملاء أو الإدارة.

يمكن حينها استبدال طريقة تحميل البيانات في `js/app.js` (دالة `vmeLoadData`) لتقرأ من خدمة مجانية مثل **Supabase** أو **Firebase** بدلاً من ملف JSON، دون الحاجة لإعادة بناء بقية الموقع، لأن كل الصفحات تتعامل مع البيانات عبر `window.VME.products` فقط.

## 7. استكشاف الأخطاء: ظهور أيقونة كبيرة تملأ الصفحة

إذا ظهرت أيقونة زرقاء ضخمة تملأ الصفحة بدل التصميم الطبيعي، فهذا يعني أن ملف `css/style.css` **لم يتم تحميله** على الاستضافة، مما يجعل أيقونات الموقع (وهي رسومات SVG) تفقد حجمها المحدد وتتمدد لملء عرض الصفحة بالكامل.

**كيف تتأكد من السبب:** افتح الموقع في المتصفح، اضغط F12 لفتح Developer Tools، اذهب لتبويب Network، أعد تحميل الصفحة، وابحث عن طلب `style.css` — إذا كان لونه أحمر أو ظهر برمز 404، فهذا هو السبب.

**الحل الأكيد:** تأكد أنك تستخدم **Cloudflare Pages** (الرابط ينتهي بـ `pages.dev`) وليس **Cloudflare Workers** (الرابط ينتهي بـ `workers.dev`). الاثنان مختلفان تمامًا رغم ظهورهما معًا في نفس قسم "Workers & Pages" بلوحة تحكم Cloudflare:

- **Cloudflare Pages** (`pages.dev`): تدعم رفع مجلد كامل بكل الملفات والمجلدات الفرعية (`css/`, `js/`, `images/`, `data/`) مباشرة عبر "Upload assets" بدون أي إعدادات إضافية — وهذا ما يناسب هذا المشروع، وهو ما يشرحه القسم 4 أعلاه.
- **Cloudflare Workers** (`workers.dev`): تحتاج ملف إعدادات خاص (`wrangler.toml` أو `wrangler.jsonc`) يحدد مجلد الأصول الثابتة (`assets.directory`)، وإن لم يُضبط بشكل صحيح فلن يتم تقديم ملفات مثل `css/style.css` أو `js/app.js` بشكل صحيح.

إذا كنت قد نشرت الموقع عبر Workers، إما اتبع توثيق Cloudflare الرسمي لضبط `assets.directory` بشكل صحيح، أو ببساطة انشر المجلد نفسه من جديد عبر Cloudflare **Pages** بدلاً من Workers — وهو الأبسط لمشروع ثابت مثل هذا.

**تحسين إضافي تم تطبيقه في الكود:** حتى مع هذا الاحتمال، تم الآن إضافة أبعاد ثابتة (width/height) لكل أيقونة داخل كود HTML نفسه، بحيث حتى لو تعطل تحميل ملف CSS لأي سبب، تظهر الأيقونات بحجم معقول بدلًا من التمدد لملء الصفحة بالكامل.

## 8. ملاحظات مهمة قبل النشر الفعلي

- المنتجات المدرجة حاليًا هي أسماء وشركات بيطرية حقيقية ومعروفة عالميًا (مثل Baytril وIvomec وFrontline وغيرها)، لكن **يجب مراجعة توفرها الفعلي في مصر ومدى الترخيص والتسجيل الرسمي لها** مع الصيدلية/الجهة البيطرية المرخصة المتعاون معها قبل الإطلاق الفعلي.
- لا تكتب أن أي منتج "معتمد" أو أن الموقع "مرخص" إلا إذا كان لديك مستند رسمي يثبت ذلك.
- الموقع لا يعرض أي أسعار بتصميمه — إذا احتجت إضافة الأسعار مستقبلًا، فهذا يتطلب تعديل الكود (js/products.js وjs/cart.js وjs/whatsapp.js) بشكل مقصود.
- راجع صفحات "الشروط والأحكام" و"سياسة الخصوصية" و"إخلاء المسؤولية" وحدّث أي بيانات تواصل فيها.
- هذا المشروع لا يقدّم استشارة قانونية أو بيطرية؛ يُنصح بمراجعة جهة قانونية أو الهيئة المصرية للدواء البيطري بخصوص متطلبات عرض المنتجات الدوائية أونلاين قبل الإطلاق الفعلي.
